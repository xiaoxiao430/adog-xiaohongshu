# 内置品牌与字体

- `adog-logo.png`：沿用本项目 `public/brand/adog-logo.png` 的爱多格正式 Logo。
- `xhs.jpg`：沿用本项目 `public/brand/xhs.png` 的小红书原始标识；源文件实际为 JPEG，按真实格式命名。
- `yahei-ui.woff2`：由本项目已使用的微软雅黑原字体生成的字形子集，包含当前小程序界面与已备20篇小红书文案；`app.css` 同时嵌入同一文件的 data URL。没有改用其他字体。

字体标识保留 Microsoft YaHei。字形已在本地检查；小红书实际基础库是否加载该 CSS 内嵌字体、手机是否使用该字体，仍须在官方 IDE 和真机核对。新增文案或用户输入超出该子集时，需要重新生成字形或以平台允许方式加载完整、已获授权的微软雅黑字体。不得把系统自动补字当成已验证的微软雅黑。
