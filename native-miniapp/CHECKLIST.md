# 原生图文发布验收清单

截至2026-11-07，下列平台及手机检查**均待完成**。本地源码检查通过不代表原生编辑器已跑通。

## 官方身份与工程

- [ ] 工具运营者使用有权使用的开发身份/AppID；顾客发笔记使用其自己当前登录的账号，不要求爱多格商家号或商家主页，不借用参考二维码的应用。
- [ ] 核对宠物医院、洗护等真实业务类目、认证材料、备案及审核要求；组件可用性以自己的应用实际测试结果为准。
- [ ] 官方 IDE 用自己的 AppID 建立项目，原样保留其生成的 `project.config.json`；导入本工程后身份正确。
- [ ] 选择基础库2.0架构；IDE≥2.3.1、客户端≥8.53、基础库≥3.120.x，当前可用版本构建无错误。
- [ ] 官方后台已配置 `jmryqyx.cn` 请求及真实图片域名；`config.js`公开AppID与官方项目一致，在自有测试工程开启内部原生预览开关。
- [ ] 爱多格Logo和小红书标识完整；CSS内嵌微软雅黑实际加载且所有可见文字使用微软雅黑，未静默换字体。备稿新字已补字形。

## 共用图库和恢复

- [ ] 无Origin原生 `bootstrap?client=miniapp` 返回普通游客Bearer；后续请求只在Authorization头携带，不获得后台权限。
- [ ] 首屏直接显示 `channel=xhs / serviceType=general` 库3张照片和 `platformCopies.xhs` 第一稿，无取图码/服务前置步骤。
- [ ] 换一批同时换照片和对应稿，不跨reviews库；无下一批保留当前内容。
- [ ] 换文案在同图1/N轮转，不联网或消耗库存；再次浏览同包能恢复修改，其他包不串稿。
- [ ] 否定、不满意、等待时间和宠物名字原样保留；超长稿阻止发布但不截断原文。
- [ ] 服务端预留到期前续租、过期链接停用、返回页面先核实；断网/响应丢失保留内容，不使用未核实的旧链接。
- [ ] 明显“回到首页”可用，退出不残留请求或续租定时器。
- [ ] 顾客流程不调用 `/consume`、下载收据或虚构已发布；现阶段只预留/续租，无提前归档。

## 官方编辑器最后一跳

- [ ] 三张原图是短期HTTPS签名URL，无Bearer/Cookie依赖，无登录重定向、无HTML报错；响应为图片且 `Content-Disposition: inline`。
- [ ] iPhone和安卓各测试3、4、5张图，数量、顺序、分辨率和画面完整；AI图示说明不被裁掉。
- [ ] 自己的真机小程序点击真实 `post-note-button`，原生编辑页实际出现所选图片、标题及正文；不是网页或系统分享面板。
- [ ] 修改后的标题正文准确预填，用户可以在官方编辑器继续修改，最终发布由用户自己点击。
- [ ] 取消、返回、重复点击、组件 `binderror`、图片过期和断网均能恢复，不出现“发布成功”假状态。
- [ ] 分别实测小红书扫码、微信扫码和系统相机扫码，记录真实到达位置；未实测的拉起路径不能写成已支持。
- [ ] 真实发布仅用已授权测试账号和本人真实内容。无用户授权不发客户帖子。
