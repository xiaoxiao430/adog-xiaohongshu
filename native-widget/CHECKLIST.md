# 小组件实际验证记录

当前以下项目均待官方IDE和手机核对。本地隔离检查通过不填作实机通过。

- [ ] 自有小组件AppID与IDE实际项目身份一致；项目类型为小组件，2.0架构编译及基础库≥3.150.0已核对（本页定义onShareChat/onCopyUrl，旧库会阻止创建页面）。
- [ ] 官方编译通过，实际包体在平台限制内；页面只有`pages/publish/index`。
- [ ] 后台配置真实API及图片域名；手机正常取得共享XHS公共库，其他库和私图不可见。
- [ ] 首屏图文对应、图序正确，图片未裁掉AI标识；图旁预览正常。
- [ ] 换稿不换图，修改后轮回或换批再回来仍保留，明显返回按钮不覆盖草稿。
- [ ] 标题或正文超长保留原话并阻止发布；断网、401、租约到期和丢响应可恢复。
- [ ] 页面离开后不再处理迟到响应；返回时刷新失效原图及预留，再启用原生按钮。
- [ ] 页面实际使用微软雅黑，新增字形无系统补字；小红书原生编辑器字体由平台控制。
- [ ] 手机点击官方`post-note-button`，顾客当前账号的原生编辑页已有当前三图、标题及正文；核对后取消返回保留改稿，不记录成已发布。
- [ ] Android与iPhone分别验证同一工程版本，包括图文预填、取消、失败恢复及当前平台内容声明。
- [ ] 由真实小红书菜单复制平台短链，检查微信扫码进入；微信分享与新访客取批不泄露原顾客令牌、签名原图链接或修改稿。
- [ ] 仅依据实际平台记录登记可分发入口；未核实前不修改`officialReady`，不自动记为已保存、已发布或出库。
