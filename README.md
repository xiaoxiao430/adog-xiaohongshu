# 爱多格小红书两周内容

西安爱多格小红书两周内容执行页：10篇图文、4条短视频，医院与洗护各7篇。

## 使用

打开 `index.html`，选择日期查看正文、参考图片与实拍清单。以爱多格Logo蓝色为主色。支持医院/洗护及图文/视频筛选，每篇含7个相关话题，一键复制标题、正文、引导与#话题。手机与电脑均可查看；本地打开无需安装依赖。

## 图片说明

外部参考图保留原貌和水印，页面附来源链接及获取说明，供拍摄学习。正式发布使用本店授权实拍。医院内容发布前由院长审核。

## 部署

纯 HTML/CSS/JavaScript。GitHub Pages 使用 main 分支根目录发布，无需构建。
